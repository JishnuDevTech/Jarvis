# JARVIS

JARVIS is a modular AI desktop assistant built from the ground up using Python and modern web technologies.

## Vision

The goal is to create a desktop companion that is always available, lightweight, and genuinely useful in everyday work.

Instead of being just another chatbot, JARVIS is designed as a personal AI operating system that can:

- 💬 Converse naturally
- 🎤 Support voice interaction
- 🧠 Remember context
- 🌐 Control web applications
- 📂 Manage files
- ⚙️ Execute modular skills
- 🤖 Integrate with modern AI models like Gemini and OpenAI

## Tech Stack

- Python
- HTML
- CSS
- JavaScript
- FastAPI
- SQLite
- Git

## Project Status

🚧 Currently in development.

The first milestone focuses on building the application's architecture and user interface before integrating AI capabilities.
